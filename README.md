# Projeto Login Full-Stack (React + Node.js)

Este é o meu primeiro projeto Full-Stack, desenvolvido como parte da minha jornada de estudos para me tornar um Desenvolvedor.

## 🎯 Objetivo
Criar uma aplicação com tela de login funcional, integrando um frontend em React com um backend em Node.js.

## 🛠️ Tecnologias Utilizadas
- **Frontend:** React, Axios, CSS
- **Backend:** Node.js, Express, CORS
- **Versionamento:** Git e GitHub

## 🚀 Como Rodar o Projeto

### Backend (server)
1. Entre na pasta: `cd server`
2. Instale as dependências: `npm install`
3. Rode o servidor: `node index.js`
4. O servidor estará rodando em `http://localhost:5000`

### Frontend (client)
1. Entre na pasta: `cd client`
2. Instale as dependências: `npm install`
3. Rode o projeto: `npm start`
4. A aplicação abrirá em `http://localhost:3000`
